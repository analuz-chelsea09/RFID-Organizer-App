## Getting Started

This repository contains the source code and project files for an RFID-powered organization system and its companion application. The physical organizer uses RFID technology to identify tagged items and help users keep track of where their belongings are stored. The schematic, materials, and CAD files needed to make the module are also included in this repo. The companion app provides a simple digital interface for viewing, organizing, adding, and locating those items.

The application was developed with Flutter and programmed primarily in Dart, allowing the interface to be designed for use across multiple platforms from a shared codebase. Visual Studio Code was used as the main development environment for writing, testing, debugging, and managing the application’s code. The repository includes the Flutter project structure, Dart source files, user-interface components, assets, configuration files, and other resources used to build and run the app.

The code also has a section in the main.dart file that enables the app to be linked to an airtable base. In order to link your app, you will need to create your own base on airtable, create a custom access key for the base, and also retrieve the base ID. Refer to the files below for help:
